\begin{abstract}
Accurate file localization is a critical first step in automated software issue resolution, yet the dominant retrieval approach---dense embedding of code chunks---is both expensive to set up and structurally unaware of repository dependencies. We present GraphManager, a retrieval framework that operates over a graph world model derived from the repository's abstract syntax tree, encoding files, classes, and functions with typed structural edges (imports, calls, inheritance). The framework supports seven retrieval methods spanning deterministic graph scoring, LLM-guided graph navigation, and standard RAG baselines, enabling direct comparison of retrieval quality against token cost. We introduce a dual-track evaluation protocol that separately reports strict commit-fidelity and same-snapshot amortized settings, preventing conflation of retrieval quality with setup cost structure. Evaluated on SWE-bench issues across multiple Python repositories, graph-guided methods achieve competitive file-level F1 while requiring substantially fewer total tokens than RAG baselines, with the graph index setup costing approximately 3$\times$ fewer embedding tokens than dense code chunk indexing. The deterministic graph scorer provides a strong zero-LLM-runtime baseline, while LLM-guided graph navigation further improves recall on structurally complex repositories. All experiments use manifest-pinned issue sets with paired per-issue deltas and bootstrap confidence intervals.
\end{abstract}
